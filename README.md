## 🚀 Interesting Projects

### 🎹 Potentia

A **sound synthesis system** built around an analog **AHDSR envelope and VCA**, with an integrated VCO.

The system uses **two Arduino Nano microcontrollers** to control the analog circuits and communicate with a **Qt desktop application**. It allows real-time configuration of envelope parameters, frequency, and waveform, while also providing a visual representation of the envelope on a display.

This project involved **analog electronics, embedded programming, serial communication, desktop software, and audio synthesis**.

---

### 🔊 Beethoven

A **distributed audio system** built using two **ESP32 microcontrollers**.

The system allows multiple speakers to communicate with a central web server, providing control over **music playback, playlists, and individual speaker volume**.

The project combines **embedded systems, wireless communication, audio processing, and web-based control**.

---

### 🎮 Touhou-FreeRTOS

A small game inspired by the Japanese **Touhou** series, developed for the **STM32F411**.

The game runs on a **128×160 LCD display** and uses a joystick as its primary input device. **FreeRTOS** is used to manage the game's real-time tasks and system components.

The project focuses on **embedded game development, real-time systems, graphics, input handling, and ARM microcontroller programming**.
